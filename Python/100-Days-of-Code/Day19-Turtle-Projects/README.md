# Day 19 - Turtle Projects

## Description

A collection of two Python projects using Turtle graphics. The projects focus on creating interactive programs, handling keyboard input, and controlling turtle objects on the screen.

## Projects

### Turtle Race

A simple racing game where multiple turtles compete against each other. The user can choose a turtle and watch the race until one reaches the finish line.

### Etch-A-Sketch

An interactive drawing program controlled with the keyboard. The turtle can move in different directions, allowing the user to draw on the screen.

## Features

* Turtle graphics
* Keyboard controls
* Interactive programs
* Randomized turtle movement
* User input
* Multiple turtle objects

## Technologies

* Python 3
* Turtle
* Random
