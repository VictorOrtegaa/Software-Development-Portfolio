# Day 16 - OOP Coffee Machine

## Description
An object-oriented implementation of the Coffee Machine project. This version refactors the previous procedural solution by applying Object-Oriented Programming (OOP) principles, making the code more modular, reusable, and easier to maintain.

## Features
- Object-oriented design
- Multiple drink options
- Resource management
- Coin payment system
- Transaction validation
- Report generation
- Modular architecture

## Technologies
- Python 3
