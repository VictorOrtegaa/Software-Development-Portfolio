# Day 17 - Quiz Project

## Description

A Python quiz application that presents questions to the user, keeps track of their score, and determines when the quiz is complete. The project uses classes and objects to organize the quiz logic and manage the questions and score.

## Features

* Multiple quiz questions
* Score tracking
* Question progression
* User interaction
* Quiz completion message
* Object-oriented programming

## Technologies

* Python 3

