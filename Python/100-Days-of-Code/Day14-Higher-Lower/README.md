# Day 14 - Higher Lower Game

## Description
A Python implementation of the Higher Lower game. The player compares two popular accounts and guesses which one has more followers. The game continues until an incorrect guess is made.

## Features
- Random account selection
- Score tracking
- Continuous gameplay
- User input validation
- Modular code using multiple Python files

## Technologies
- Python 3
