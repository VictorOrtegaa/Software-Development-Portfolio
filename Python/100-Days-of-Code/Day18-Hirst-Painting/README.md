# Day 18 - Hirst Painting

## Description

A Python program that creates a colorful dot painting inspired by the artwork of Damien Hirst. The project uses Turtle graphics to draw a grid of randomly colored dots.

## Features

* Turtle graphics
* Randomly generated colors
* Dot grid painting
* RGB color values
* Automated drawing

## Technologies

* Python 3
* Turtle
* Random
