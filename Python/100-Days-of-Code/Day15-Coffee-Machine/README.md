# Day 15 - Coffee Machine

## Description
A Python simulation of a coffee machine that allows users to order different drinks, processes coin payments, manages available resources, and generates reports. The program uses functions and dictionaries to organize the machine's behavior.

## Features
- Multiple drink options
- Resource management
- Coin payment system
- Transaction validation
- Report generation
- Continuous user interaction

## Technologies
- Python 3
