# Day 12 - Number Guessing Game

## Description
A Python game where the player must guess a randomly generated number between 1 and 100. The game includes easy and hard difficulty levels with a limited number of attempts.

## Features
- Random number generation
- Easy and hard difficulty modes
- Attempt counter
- Feedback after each guess
- ASCII art interface

## Technologies
- Python 3
